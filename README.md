## Layout

| Folder | Patterns |
|---|---|
| `arrays-hashing/` | arrays, strings, hash maps/sets, prefix sums |
| `two-pointers/` | two pointers, sorting-based tricks |
| `sliding-window/` | fixed and variable windows |
| `stack/` | stacks, monotonic stacks |
| `binary-search/` | binary search, search on the answer |
| `linked-list/` | linked lists, fast/slow pointers |
| `trees/` | binary trees, BSTs, DFS/BFS on trees |
| `tries/` | prefix trees |
| `heap-priority-queue/` | heaps, top-k, two heaps |
| `backtracking/` | subsets, permutations, combinations |
| `graphs/` | BFS/DFS, union-find, topological sort, shortest paths |
| `dynamic-programming/` | 1-D and 2-D DP |
| `greedy/` | greedy choices |
| `intervals/` | merging and scheduling intervals |
| `math-bit-manipulation/` | math, bit tricks |

Files are named `<problem number>-<problem-slug>.py`, e.g. `arrays-hashing/0001-two-sum.py`. The progress table above is rebuilt automatically by a GitHub Action on every push.
